# SVG renderer v1 archive

This directory preserves the exact renderer, browser harnesses, and screenshot
used by the first 192-glyph explorer measurements. The
[manifest](manifest.json) records every archived SHA-256 and the five receipts
checked against those files before the next behavior revision.

The archived code retains its original relative paths. It records the original
`screensaver/svg-preview` source tree; the current
[explorer guide](../../../../screensaver/svg-preview/README.md) documents the
live version.
