# Smythe 0.8.1

[GitHub release](https://github.com/petehottelet/smythe/releases/tag/v0.8.1) ·
[PyPI package](https://pypi.org/project/smythe/0.8.1/)

Smythe 0.8.1 is a security release. In 0.8.0, a plan generated by a model could
make Smythe start a local program and pass it environment variables. This
release closes that hole and several places where model replies or provider
responses could get past the execution envelope's checks. Upgrade if you use
`LLMArchitect` (the default `Swarm` planner) with `MCPToolRuntime`, or if you
decode images from providers.

```bash
pip install "smythe[openai]==0.8.1"
# For native Claude Messages:
pip install "smythe[anthropic]==0.8.1"
```

## What changes

- **Generated plans are data.** `LLMArchitect` parses each plan under a strict
  schema: no MCP servers, commands, URLs, environment variables, per-node
  models or unknown fields; at most 8 nodes and 5 levels by default. MCP
  servers come only from developer configuration. Resuming a checkpoint
  written before 0.8.1 drops its MCP servers.
- **Untrusted images** are decoded only as PNG, JPEG, GIF or WebP.
- **Files with prompts and responses** are created owner-only on POSIX.
- **Fail-closed judgment.** Verifier verdicts, supervisor proposals and router
  replies are read strictly; output cut off at the token limit fails its node
  instead of counting as complete.
- **Budgets and durable runs.** Retries and tool turns reserve their estimated
  cost before dispatch. Durable workflows settle provider rejections that
  happen before any model work, such as a rate limit, at zero cost.
- **Autotune** promotes on a paired Student-t lower bound and seals each
  challenger's holdout.

Full behavior and fixes are in the [changelog](../CHANGELOG.md#081---2026-09-22).

## Upgrade from 0.8.0

Smythe is pre-1.0, and this patch release changes behavior that 0.8.0 accepted
where that was needed to close a security or correctness gap. Check these
before upgrading:

- **Default model.** `Swarm`, `LLMArchitect`, `ConstrainedArchitect` and the
  `WhiteRabbit` classifier default to `claude-opus-5-5` (was `claude-opus-4-8`).
- **Concurrency.** `Swarm()` defaults to `parallel=False`, which now also
  applies to `execute_async()`, `resume()` and `aresume()`. Pass
  `parallel=True` to keep concurrent execution.
- **Generated plans** that exceed the limits or use removed fields are retried.
  Raise `LLMArchitect(max_nodes=..., max_depth=...)` if you need larger plans.
- **Truncation.** With the Anthropic, OpenAI and Gemini SDK providers, output
  that stops at the token limit fails the node under its failure policy.
  Raise `max_tokens` for long deliverables.
- **Verifier and supervisor** replies that 0.8.0 read loosely may now fail a
  gate or make no revision. Have judges end with a standalone `PASS` or `FAIL`
  line or a `Verdict:` line; see [Verification](verifier.md) for the exact
  rules.
- **Autotune** campaigns started under 0.8.0 are not resumed, and an explicit
  `--campaign-id` campaign created by 0.8.0 must be finished on 0.8.0.
  Re-testing a challenger whose holdout was used exits with code 8.
- **Rollback.** Checkpoints are written as version 4, which 0.8.0 cannot read,
  and a durable journal with a settled provider rejection cannot be resumed
  by 0.8.0. A durable run started under 0.8.0 cannot be resumed if its next
  call's prompt changed (a planner retry, or a node that depends on a skipped
  node); finish it on 0.8.0 or start a new run.

## Verify a checkout or package

Install `.[dev,openai,anthropic]` from the tagged checkout and run:

```bash
python -m ruff check .
python -m mypy
python -m pytest tests/ -q
python examples/14_durable_text_workflow.py
```

The example uses fixture responses and makes no provider calls. The
[distribution guide](distribution.md) covers archive inventories, source-to-wheel
reproduction, clean installed-package checks and the source test profile.
Package README links resolve against `v0.8.1`. The release workflow retains
the actual published distributions and SHA-256 hashes; verify downloaded PyPI
bytes against that receipt as described in [Releasing](../RELEASING.md).
